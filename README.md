# Student Expense Tracker 💰

A simple Python application that helps students record and monitor their daily expenses.

## Features

- Add new expenses
- Categorize expenses
- View recorded expenses
- Calculate total spending
- Automatically save expense data
- Display the date of each expense

## Technologies Used

- Python
- JSON
- File Handling
- Datetime
- Basic Python Data Structures

## How It Works

The program provides a simple menu:

1. Add Expense
2. View Expenses
3. Show Total Spending
4. Exit

Expenses are stored locally so they can be accessed again later.
